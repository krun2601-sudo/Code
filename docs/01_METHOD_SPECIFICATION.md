# EA-CML-H 方法规范

## 1. 输入、输出与时间基准

每个决策周期输入：

- 当前单调时钟 \(t\)、周期 \(\Delta t\) 与步号；
- 每台设备最新遥测：方位、俯仰、角速度、倍率、连接状态、采样时刻；
- 每台设备最新命令结果：是否发送、是否 ACK、状态与错误；
- 每台设备最新帧状态：帧标识、主机估计采集/接收时刻、分辨率与轻量质量量；
- 固定的设备几何、限位、相机内参与安全角域；
- 已确认覆盖集合、未完成任务与设备执行状态。

输出是每台设备的绝对方位/俯仰目标，未开放的控制维度输出 `None`。动作只在安全角域与机械限位的交集中产生，携带当前 `issued_t` 和有限正租约。策略不访问 SDK、网络、原始视频或仿真真值。

实机各时刻使用同一会话的主机单调时钟；不得跨进程直接相减，也不得解释为 UTC。帧 `capture_t` 是由接收时刻和配置时延得到的主机估计，不是硬件曝光时间戳。

## 2. 几何覆盖模型

搜索区域离散为等权单元中心 \(\mathcal C=\{\mathbf x_m\}_{m=1}^M\)。设备 \(i\) 的候选视向为 \(q=(\theta_{iq},\phi_{iq})\)。用平台提供的完整安装旋转和云台逆解将空间点转换到本地角度，禁止只用世界向量的 `atan2` 代替安装变换。

固定倍率 \(z^\star\) 下，由内参得到水平、垂直视场：

\[
\alpha_i^h=2\arctan\frac{W_i}{2f_{x,i}(z^\star)},\qquad
\alpha_i^v=2\arctan\frac{H_i}{2f_{y,i}(z^\star)}.
\]

保守边界因子 \(\mu\in(0,1)\) 作用在半视场上。若单元在视域/遮挡门内，且相对候选中心的包角方位差与俯仰差分别不超过 \((1-\mu)\alpha_i^h/2\) 和 \((1-\mu)\alpha_i^v/2\)，则 \(A_{iqm}=1\)。正式结论称为“基于配置几何模型的覆盖”。

所有主方法和基线使用相同的 \(A_{iqm}\)、可达性与安全角域。若存在全体活动设备均不可达的单元，任务在开始前失败，不允许把分母改成可达单元后继续声称完成原区域。

## 3. 执行确认事件

设备 \(i\) 对视向 \(q\) 的状态机为：

```text
IDLE/HOME → MOVE → SETTLE → DWELL → FRAME_CONFIRM → COMPLETE
                     ↘ timeout/stale/error/frame-timeout ↘ RECOVER/REPLAN
```

### 3.1 MOVE

周期性重发同一绝对目标，直到误差进入到位门，或发生明确命令错误、遥测陈旧/掉线、运动超时。ACK 只用于识别链路失败，不触发到位。

### 3.2 SETTLE

在连续 \(w_s\) 秒内同时满足：

\[
|\operatorname{wrap}(\theta_i-\theta_{iq})|\le\epsilon_\theta,
\quad |\phi_i-\phi_{iq}|\le\epsilon_\phi,
\]

\[
|\dot\theta_i|\le\epsilon_{\dot\theta},
\quad |\dot\phi_i|\le\epsilon_{\dot\phi}.
\]

任一条件破坏都会重新累计稳定窗口。

### 3.3 DWELL

从连续稳定条件首次满足后的时刻开始累计 \(w_d\)。驻留期间姿态门被破坏则返回 SETTLE，不把已经累计的驻留保留到下一次。

### 3.4 FRAME_CONFIRM

要求收到不少于 \(n_f\) 个在驻留开始之后产生的新帧；帧必须满足：

- 设备 ID 与当前任务一致；
- 帧标识比进入任务时新；
- 帧年龄小于上限；
- 解码成功且分辨率与当前标定一致；
- 若启用亮度/对比度/清晰度门，则相应指标达标。

帧门只确认“相机在稳定后产生了新的可用图像”，不代表图中存在目标，也不评价目标检测器。

### 3.5 COMPLETE

仅在上述条件全部成立时设执行事件 \(e_{iq}=1\)，以该时刻 \(t^c_{iq}\) 更新覆盖：

\[
y_m^{\mathrm{exec}}(t)=
\mathbf 1\!\left[
\exists(i,q): A_{iqm}=1,\ e_{iq}=1,\ t^c_{iq}\le t
\right].
\]

已确认集合只做并集，故 \(C^{\mathrm{exec}}(t)\) 单调不减；未完成任务无法提前计入。

## 4. 设备相关完成时间模型

commissioning 对每台设备执行安全角域内的方位单轴、俯仰单轴和双轴转移。单个样本从首次发出新目标命令到 FRAME_CONFIRM 完成，响应量已经包含转动、稳定、驻留与新鲜帧等待。特征为：

\[
z=\left(1,
[\Delta\theta]_+,[-\Delta\theta]_+,
[\Delta\phi]_+,[-\Delta\phi]_+\right),
\]

以及设备 ID、起终点、命令/到位/稳定/帧时刻和总完成时间 \(\Delta t\)。推荐每台设备 60 个有效样本，并按预先生成的样本 ID 划分为 36 个拟合、12 个校准和 12 个测试样本；最低可接受规模为 24/12/12。相反方向和角程应在三个子集中均有代表。

拟合集使用 Huber IRLS；每个加权子问题由非负最小二乘求解，截距和四个方向斜率均非负，\(\ell_2\) 稳定项仅作用于斜率。独立校准集使用单侧 split-conformal 残差校准。令校准残差为 \(r_j=\Delta t_j-\hat\tau_i(z_j)\)，风险水平为 \(\alpha\)，取排序分位位置 \(k=\lceil(n_{cal}+1)(1-\alpha)\rceil\)。必须满足 \(\alpha\ge 1/(n_{cal}+1)\)，否则工具拒绝拟合，不对超出样本范围的分位位置作静默截断。时间上界为：

\[
\widetilde\tau_i(q,q')=
\max\{\tau_{\min},\ \hat\tau_i(z)+r_{(k)}\}.
\]

\(\alpha\) 默认 0.1。若拟合样本和未来转移可交换，该上界具有有限样本的边际覆盖解释；它不是对任意非平稳故障的保证。独立测试集报告 MAE、RMSE、偏差、P90 绝对误差、低估率、上界经验覆盖率和区间宽度。特征、模型结构和风险水平在查看测试集与主比较结果前冻结。

## 5. 计划构造

设当前每台设备的计划序列为 \(S_i\)，预测完工时间为 \(L_i\)，未确认单元集合为 \(\mathcal U\)，当前计划已保留的单元集为 \(\mathcal P(\mathcal S)\)。把候选 \(q\) 插入设备 \(i\) 的位置 \(r\) 时，新增覆盖量为

\[
\Delta M_{iqr}=\left|\mathcal B_{iq}\cap
\left(\mathcal U\setminus\mathcal P(\mathcal S)\right)\right|.
\]

用 \(\widetilde\tau_i\) 从设备当前实测姿态重算插入前后的完整加性路由成本，令 \(\Delta\widetilde L_{iqr}\) 为二者差值的非负部分，再计算团队瓶颈增量

\[
\Delta\widetilde T_{iqr}=
\left[
\max\{L_i+\Delta\widetilde L_{iqr},\max_{j\ne i}L_j\}
-\max_jL_j
\right]_+.
\]

EA-CML-H 的执行感知插入评分为

\[
S_{iqr}^{\mathrm{exec}}=
\frac{\Delta M_{iqr}}
{\Delta\widetilde T_{iqr}+\lambda_b\Delta\widetilde L_{iqr}
+\lambda_u U_{iqr}+\varepsilon},
\]

其中 \(U_{iqr}=\Delta V_{iqr}+h_i\Delta\widetilde L_{iqr}\)：\(\Delta V_{iqr}\) 是插入前后路由不确定宽度和之差的非负部分，\(h_i\) 由遥测年龄、角速度和帧健康比加权得到。默认 \(\lambda_b=0.15\)、\(\lambda_u=0.25\)、\(\varepsilon=10^{-6}\)。固定随机种子仅用于相同评分的可复现打破，不改变可行性判定。

求解顺序：耦合插入得到可行计划；冗余删减；在冻结的时间与候选评估预算内执行有限轮设备内 2-opt。当前实时实现不运行 ALNS；优化器只产生计划，不直接把计划视为覆盖证据。

## 6. 事件触发的剩余任务修复

发生以下任一事件时冻结已确认集合，并仅对残余集合重新计划：

- 遥测陈旧、掉线或显式设备暂停；
- 命令结果为错误/拒绝；
- MOVE/SETTLE/DWELL/FRAME_CONFIRM 任一阶段超时；
- 实际完成时间超过预测上界；
- 当前任务因安全门失效而不可继续。

重规划使用各设备当前实测姿态作为新起点。已确认任务不回滚；尚未确认的当前任务可重新分配。设置最小重规划间隔与事件去抖，避免一次持续故障在每个 10 Hz 周期触发规划风暴。

条件终止性质：若故障在有限时间后停止，剩余每个单元至少有一个活动设备可达，且所有被下发的可达任务在有限时间内通过完成门，则每次完成严格减少有限残余集合，算法最终完成。该结论不声称在持续故障或不可达区域下仍能完成。

## 7. 五个主比较方法

五种方法共用几何、状态机、动作门、完成门和日志：

1. **FPR**：按设备分区，区内蛇形访问；异常后不跨区修复。
2. **MAG**：按边际覆盖/当前姿态标称机动代价贪心追加，不做全位置插入。
3. **Nominal-CML-H**：采用标称端到端时间的静态插入—删减—2-opt；执行过程中不修改剩余计划。
4. **Measured-CML-H**：采用实测时间模型的静态插入—删减—2-opt；无事件修复。
5. **EA-CML-H**：实测时间模型与事件触发残余任务修复均启用。

另做机制消融时可关闭帧确认、实测模型或事件修复，但“无帧确认”只用于机制分析，不能与完整方法共用相同的执行覆盖定义后声称公平主比较。

## 8. 默认安全参数（实验前值）

以下只是保守初值，必须在 commissioning 后冻结并记录：

| 参数 | 初值 | 说明 |
|---|---:|---|
| 软件安全方位 | ±35° | 位于机械 ±130° 内；覆盖当前 ROI 预计所需方向 |
| 软件安全俯仰 | −20° 至 20° | 位于机械 −85° 至 25° 内 |
| 固定倍率 | 10× | 必须逐机验证 `zoom_known` 与 `zoom_stable` |
| 姿态误差门 | 1.0° | 方位、俯仰分别判定 |
| 角速度门 | 1.0°/s | 需用真实遥测噪声核验 |
| 连续稳定窗口 | 0.30 s | 3 个 10 Hz 周期只是下限，按时间而非计数实现 |
| 驻留 | 0.80 s | 与平台原 `minimum_dwell_s` 一致 |
| 新帧数 | 3 | 驻留开始后产生 |
| 帧年龄上限 | 0.60 s | 继承现场配置，预检时必须满足 |
| 动作租约 | 0.50 s | 每周期更新；停止时由平台仲裁 |
| 重规划去抖 | 0.50 s | 避免持续故障重复触发 |

参数改变后须生成新配置哈希；不同方法之间不得单独调阈值。
