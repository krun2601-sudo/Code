# 第二阶段数据交接清单

完成实物实验后，请将以下内容原样放入新的数据目录，不要先用 Excel 手工筛选：

1. 每次 commissioning 和主运行的完整会话文件夹；
2. 批次运行计划 CSV/JSON；
3. 实际使用的展开配置、私有配置的脱敏副本及其 SHA256；
4. `user_policy.py`、平台补丁安装报告、平台源码快照清单；
5. 预检报告、操作员记录、异常/急停记录；
6. 若有，四机搭建照片与不含网络敏感信息的布置图；
7. 任何与计划不一致的重跑、参数修改或手动干预说明。

阶段二将按以下顺序工作：

- 校验完整性、哈希和运行计划一致性；
- 冻结有效/无效/失败运行标签，不根据性能筛选；
- 拟合 commissioning 时间模型并只在留出集验证；
- 生成主指标、统计检验、覆盖曲线、预测校准与故障恢复图；
- 将真实结果自动写入中文主稿的结果占位符；
- 根据证据强度收缩或支持摘要、贡献和结论；
- 再生成英文 RA-L 稿与匿名公开包。

在收到数据前，稿件中所有 `[待实测]`、`[待填写]`、`[自动生成]` 均必须保留。它们不是排版遗漏，而是防止实验前虚构结论的证据边界。
