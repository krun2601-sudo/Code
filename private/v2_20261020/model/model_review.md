# V2执行时间模型冻结前审核

- 数据合同：4台设备各60次转移；训练、校准、测试分别为36/12/12次。共接受240次，拒绝0次。训练数据来自两个仅含训练标签的完整运行；校准与测试各来自一个独立完整运行，未发生运行级集合泄漏。
- 时间定义：从首次相关速度指令发出，到实测姿态稳定、驻留完成且收到到位后的第3个不同新帧。模型没有再次叠加驻留时间。
- 模型结构：每台设备单独拟合非负Huber-NNLS点模型；小、中、大转角的单侧余量由48次独立校准转移按有限样本秩计算。
- 分档校准样本量：小/中/大分别为19/15/14；单侧余量分别为1.9131/8.7019/6.5262 s。
- 独立测试：48次中43次被上界覆盖，经验覆盖率89.58%；点预测MAE为4.2314 s，RMSE为5.4792 s。目标覆盖率0.90的精确单侧二项检验未发现覆盖率偏低（p=0.5314），95% Clopper–Pearson区间为[0.7734, 0.9653]。
- 分档测试覆盖：小转角9/12（75.0%）、中转角16/18（88.89%）、大转角18/18（100%）。小转角样本量有限且波动较大，但没有使用测试残差重新选择余量；理论结论仍按“实际转移不超过校准上界”的条件形式表述。
- 校准集到位误差最大值：方位1.000°、俯仰0.893°。规划与确认统一采用1.0°鲁棒视场侵蚀。
